# 🇮🇳 English to Hindi Typing

A simple and user-friendly web-based English to Hindi Typing tool that helps users type Hindi text using English keyboard input.

## 🚀 Features

* English to Hindi transliteration
* Real-time Hindi text conversion
* Simple and clean interface
* Responsive design
* Easy copy and paste functionality
* Fast and lightweight
* Works on desktop and mobile devices

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Unicode / Hindi Transliteration

## 📌 How to Use

1. Enter English words using your keyboard.
2. The tool converts the input into Hindi text.
3. Review and edit the generated Hindi text.
4. Copy the Hindi text and use it anywhere.

### Example

```text
Input:    mera naam abhishek hai

Output:   मेरा नाम अभिषेक है
```

## 🌐 Project Purpose

This project demonstrates frontend development, JavaScript-based text processing, Unicode handling, and responsive web design.
